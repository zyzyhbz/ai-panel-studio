# 行为评测（evals/）

- Owner：AI/Agent
- 目的：在不调用真实模型的前提下，验证 agent 包**整条链路**（阵容 → 决策/发言 → 共识 → 总结）与行为门禁。
- 关联：[AGENT-BEHAVIOR](../docs/AGENT-BEHAVIOR.md) §10、[AGENT-API](../docs/AGENT-API.md)

## 跑法

```powershell
cd D:\AI开发\ai-panel-studio
.\scripts\pnpm.ps1 exec tsx evals/run.ts
# 报告：evals/report/baseline.mock.md / baseline.mock.json
```

- 默认每个 mock 调用注入 15ms 延迟（`--latency=0` 可关），用来测出可读的阶段耗时。
- 退出码：全部门禁通过为 0，有未通过项为 1（可接 CI）。
- 不读 Key、不发网络请求。真实模型基线要等后端在 `LLM_MODE=real` 下跑同一套指标。

## 结构

| 文件 | 作用 |
| --- | --- |
| `simulate.ts` | 用 `MockLLMClient` 跑一整场（等价于后端 SessionRunner 的简化版），返回消息/洞察/耗时 |
| `run.ts` | 计算指标、对照 `thresholds.json`、生成 md/json 报告 |
| `thresholds.json` | 门禁阈值（改阈值等于改验收标准，需要 PM 同意） |
| `report/` | 生成物（可提交，便于交付时展示基线） |

## 指标（15 项门禁）

| 指标 | 阈值 | 说明 |
| --- | --- | --- |
| JSON 合法率 | ≥95% | roster/decision/insight 的一次解析成功率 |
| 1–2 句合规率 | ≥95% | 每条发言句末标点计数 ∈[1,2] |
| 字数合规率 | ≥98% | 专家 ≤120 字、主持 ≤60 字 |
| 专家覆盖率 | 100% | 每位专家至少发言 1 次 |
| 单人最大占比 | ≤35% | 防止一个人独角戏 |
| 主持占比 | ≤34% | 主持人 ≤4 席 |
| 机械轮转违规 | 0 | 不存在周期 2–4、重复 ≥2 次的发言序列 |
| 相邻重复率 | ≤5% | 相邻两条发言 3-gram Jaccard > 0.5 的比例 |
| 极性种类 | ≥3 | 阵容的立场极化程度 |
| 存在反对侧 | 全部 | 必须有 oppose/strong_oppose |
| 共识证据合法率 | 100% | 每条洞察的 evidence 都能在消息里找到 |
| 分歧双人证据率 | 100% | divergence 的证据来自 ≥2 位发言者 |
| 总结段数 | =3 | 共识 / 分歧 / 未决 |
| 总结无 JSON 痕迹 | 全部 | 无 `{}`、字段名、列表符号 |
| 单场成本 | ≤¥0.3 | 按 deepseek-flash 峰时价估算 |

## 重要说明

**mock 通过 ≠ 行为达标。** mock 验证的是：

1. schema 与解析链路正确；
2. 守卫（准入集、连续上限、覆盖强制、收尾）真的生效；
3. 降级路径（超时/空输出/坏 JSON/复读/超长）不会把会话跑崩；
4. 分布与覆盖的下限。

它**不能**证明真实模型会说什么、有没有真碰撞。真实质量要等 AI-04 在 `real` 模式下跑同一套指标 + 人工抽检。
