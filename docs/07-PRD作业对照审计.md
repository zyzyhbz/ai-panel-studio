1. “可随时录制”= 语义事件自动记录 + 时间线回放，不是视频录制；视频/音频为 P2 非目标。

4. “生产级质感”= 流式、回放、异常态、响应式、测试、可运行 README，不是企业级权限/多租户。
5. “至少 5 条高质量样例”= FR-14 的可检查清单：5 种状态、字段非空、颜色唯一、立场 ≥3 类、1 条 ≥8 轮可回放。

8. **视觉验收**：三档截图与“像演播厅”需要人工过目，不能只靠测试通过。
9. **提交邮件**：最终要按 §12.4 发到 `xulei@wisquest.com`，附 zip + 文档 + 仓库邀请。
