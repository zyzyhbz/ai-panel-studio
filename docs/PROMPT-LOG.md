## 1. 【需求/PRD 阶段】从题目到可执行产品定义

**原始 Prompt（节选）**

```text
将这个图片内的文字提取，这是一道实习公司给我的测试题，要求我72小时内做完，才能获得面试机会。
```

```text
你先将我的话理解一遍，然后跟我同步。
（附：用户需求笔记；要求分配产品经理、前端、后端、测试四个角色）
```

```text
技术栈需要再单独分析，你需要从产品功能适配度方面给出建议的组合并评估可行性，工程量，难度等。
```

**当时意图**

先把题目、用户诉求、角色约束整理成同一份产品定义，避免直接进入“让 AI 写代码”。

**挑战与修正**

- 题目给的是功能清单，用户笔记给的是价值诉求，两者颗粒度不同；直接写 PRD 容易漏掉“可回放/多议题隔离”等隐含要求。
- 先做技术选型和角色边界，再写 PRD；把“快/全/结构化/回放/透明/多议题”翻译成可验收的 FR/AR/NFR。

**产出**

`PRD.md`、`01-技术选型.md`、`02-角色与协作SOP.md`、`TASKS.md`

## 2. 【SDD 阶段】数据建模与 API/SSE 契约

**原始 Prompt（节选）**

```text
你是 AI Panel Studio 项目的后端工程师。
先读 PRD、ER、API 契约、SSE 契约、技术选型、角色 SOP、任务板。
G1 任务：只做设计，不写生产代码。
产出 docs/BACKEND-PLAN.md：
- 逐项评审 ER/API/SSE 是否可落地
- 模块与目录、SessionRunner 状态机
- 事件 seq、事务、WAL、并发隔离、进程重启恢复
- SSE 补发/心跳/背压
- mock LLM 与测试清单
- 对契约的修改建议
硬约束：不改共享文档、不写代码、不读 Key。
```

**当时意图**

让后端从可实现性反推契约，而不是 PM 单方面写一份“看起来合理”的 API。

**挑战与修正**

- PM 初稿容易把“同步生成阵容”“SSE 补发”“seq 分配”写得太理想；需要后端指出事务边界和失败路径。
- 明确要求“只评审、不写代码”，避免契约没冻结就产生返工。

**产出**

`ER.md`、`03-API契约.md`、`04-SSE事件契约.md`、`BACKEND-PLAN.md`（待回）

## 3. 【DDD 阶段】前端页面、组件与状态流转

**原始 Prompt（节选）**

```text
你是 AI Panel Studio 项目的前端工程师。
先读 PRD、API/SSE 契约、技术选型、角色 SOP、任务板。
G1 任务：只做设计，不写页面代码。
产出 docs/FRONTEND-PLAN.md：
- 页面/路由、三档响应式布局
- 组件树、Zustand + reducer 边界
- SSE 客户端、断线重连、流式缓冲
- 直播/回放共用 reducer
- 设计 token 与“演播厅感”
- 低保真线框
- 对 API/SSE 的修改建议
硬约束：不改共享文档、不写代码、不定义 Agent 行为。
```

**当时意图**

先把“演播厅感”拆成布局、组件、状态和动效约束，再让前端写页面，避免做成通用后台。

**挑战与修正**

- “沉浸感”是主观词，必须落成三栏布局、专家色、聚光、独立滚动、状态脉冲等可验收项。
- 直播和回放如果各写一套状态，后期一定漂移；要求共用 reducer。

**产出**

`FRONTEND-PLAN.md`（待回）、后续 `apps/web/**`

## 4. 【Agent 行为阶段】Prompt、上下文与发言调度

**原始 Prompt（节选）**

```text
你是 AI Panel Studio 项目的 AI/Agent 工程师。
你的边界是 Agent 行为与上下文工程，不是第二个后端。
产出 docs/AGENT-BEHAVIOR.md：
- 人设生成、主持人行为、发言调度
- 上下文窗口、token 预算、跨会话隔离
- 公开状态/隐藏 CoT 边界
- 共识/分歧判定与证据
- 五类 LLM 输出契约
- 失败降级
- 5 个议题的行为 eval
- 对 API/SSE/ER 的修改建议
硬约束：只写 packages/agent 与 docs，不碰 API/DB/SSE/UI，不读 Key。
```

**当时意图**

把 prompt 从“散落在后端/PM 的字符串”变成有 owner、有版本、有 eval 的行为层。

**挑战与修正**

- “发言调度”很容易写成另一个后端；必须切开“行为编排（AI）”和“运行时编排（后端）”。
- “过程透明”不能泄露隐藏 CoT；只能暴露状态、意图、公开关注点。

**产出**

`AGENT-BEHAVIOR.md`（待回）、`docs/prompts/`、`packages/agent/**`、`evals/**`
