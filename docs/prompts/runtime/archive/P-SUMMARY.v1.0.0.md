# P-SUMMARY v1.0.0 / v1.1.0（主持人总结）

- 实现：`packages/agent/src/prompts/summary.ts`
- 输出：**纯文本三段** → `parseSummaryText` → `normalizeSummary` / `buildFallbackSummary`
- 参数：`deepseek-flash` / **thinking 开启（v1.1）** / text / temperature 0.5 / max 500 tokens / 超时 **90s（v1.1）**
- 对应：AR-08；FR-10（自然语言、不显示 JSON）；契约 §1.4（`isFallback`）

## v1.1 新增：把「仍未解决」写进第 3 段

深度讨论改版后，讨论可能带着旧分歧收束（这是允许的），但必须**明确说出来**，不能用"总体上都认为"糊过去。
实现方式：`buildDebateMap(snapshot).saturation.acceptedUnresolved`（超窗口的旧挑战 + 旧张力）直接注入 prompt：

```text
# 仍未解决（第 3 段必须点到其中 1–2 条，不要含糊带过）
- 「再培训成本该谁承担」由许澜提出，陈默未正面回答
- 分歧在于这是压缩还是重构

# 注意
讨论跑到了安全上限才收，说明还有没聊完的线头——第 3 段要明确说出“哪些问题没被解决”。
```

第 3 段的写作要求同步改为：**还有什么没解决（有「仍未解决」清单时至少点 1–2 条）** + 一个可带走的判断。
这一条是 `summary` 与 `hard_cap` 语义对齐的关键：36 轮硬收时必须承认"没聊完"。

## 为什么是纯文本

FR-10 要的是"主持人以自然语言总结"，要是一份 JSON 再被前端拼成句子，那就是模板文案，不是总结。
所以：模型直接写三段自然语言，`normalizeSummary` 只做长度与 JSON 痕迹校验。

## System

```text
你是这场圆桌的主持人，讨论已经结束，你要给观众一段总结。
你的总结要让人**不读全文也能拿走结论**，但绝不能编造讨论里没有的东西。

# 硬性要求
（全局 5 条）
5. 只写自然语言段落，不写 JSON、不写字段名、不用列表符号、不用小标题。
6. 不要在总结里出现新的主张或新的数据。
```

## User 模板

| 插槽 | 说明 |
| --- | --- |
| `{{topic}}` | 议题 |
| `{{turnCount}}` / `{{speakerCount}}` | 讨论规模 |
| `{{contextBlock}}` | 现场 + 统计 + 最终快照 |
| `{{insights}}` | **最终**共识/分歧/待验证清单（总结只能以此为准） |
| `{{closingLine}}` | 主持人刚才那句收尾发言，避免重复 |

正文要求（原文）：

1. 写成 **3 段**，段间空一行：
   - 第 1 段：哪些点形成共识（没有就直接说"这场没有形成明确共识"）；
   - 第 2 段：主要分歧是什么，双方各自主张（要写出争的是什么）；
   - 第 3 段：还有什么没解决，以及看这场讨论的人可以带走的一个判断。
2. 总长 180–320 字，每段 1–3 句。
3. 语气像主持人在收尾，可以有一句态度，但不要煽情。
4. 不逐个人复述，不写"某某说……某某又说……"。
5. 不出现 JSON 字段名、不出现大括号、不出现编号列表。
6. 某类为空就明确说明为空，不要用模糊表述盖过去。

## 校验（`normalizeSummary` / `parseSummaryText`）

| 检查 | 阈值 | 处理 |
| --- | --- | --- |
| JSON 痕迹 | `{}`、`"insights":`、`"content":`、`evidenceMessageIds`、`"type":"…"` | 直接抛 `AgentParseError`，触发重试或模板兜底 |
| 段数 | 2–4 段，目标 3 段 | 1 段记 `too_few_paragraphs`（仍可落库但 `ok=false`） |
| 长度 | 20–400 字（目标 180–320） | 超长按段截断；过短记 `too_short` |

## 兜底（`buildFallbackSummary`）

总结超时/两次失败/JSON 泄漏时，用**既有 insights 重排**成三段，`summary.isFallback=true`：

```text
这场里，几位在一个点上收拢了：{{consensus1}}；{{consensus2}}。这一点上没有出现明显的反对。
（没有共识时：这场没有形成明确共识，几位更多是从各自角度补充，各说各的部分。）

没有谈拢的是：{{divergence1}}；{{divergence2}}。
（没有分歧时：讨论中没有出现正面冲突，更多是侧重点不同。）

还悬着的是：{{open1}}；{{open2}}。如果要带走一句话：这场讨论没有给出标准答案，但把分歧的位置标出来了。
```

约束：只重排已有 insights，不新增任何主张；模板总结也要过同一条 `normalizeSummary` 校验。
